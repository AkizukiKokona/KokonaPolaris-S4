## 0. 一句话

**G2 的判据以前是一句话，现在是一把有分辨力的尺子** —— 而且这把尺子自己先过了双向校验：
**构造上分离的 oracle 必须 PASS、故意串味的 leaky 必须 FAIL**，缺任何一个都不能采信后面的数字。

---

## 1. 为什么 G2 是**结构性门**（不是配方门）

40ch 混合 latent = 语义 8ch（**是什么**）+ 细节 32ch（**长什么样**）。
若不显式监督，主干会把两个通道**都塞满**信息 ⇒ 画风解耦失效 ⇒
**三层控制栈的 L1（承担 ~90% 调用量）全盘作废**。

⇒ 因此 G2 不过，意味的是**改架构**，不是调配方。这与 G3.5 同属「结构性门」，
与 G1/G4/G5/G7 那些「只影响上限」的配方门性质不同。

---

## 2. 判据的演化（**三次口径修正，每次都改变了结论**）

### 2.1 原始形态：相对降幅（❌ 作废）

```
依赖度 = 扰动后误差 / 未扰动误差        ← 分母是「模型自己的误差」
```

**致命缺陷**：完美分离时未扰动误差 `base ≈ 0`，除法把任意微扰放大成几百倍。
历史实测：干净样本的 shuffle 扰动报出 **495% 的假失败**。

### 2.2 加 eps（❌ 也不算修好）

给分母托一个 `1e-6` 之后，净效果是**把一个退化换成另一个退化**：

| 被测对象 | 期望 | 加 eps 后的实测 |
|---|---|---|
| **oracle**（构造上完全分离） | PASS | ❌ **`nan`**（0/0） |
| **leaky**（语义分支实际读细节块） | FAIL | ❌ **`1.000`**（"看起来完美"） |

⇒ **判据完全失去分辨力**。这条必须写进文档：**「加个 eps 让它不崩」不是修复**。

### 2.3 现有形态：不变性口径（✅ 采用）

```
依赖度 = ‖branch(x') − branch(x)‖ / ‖branch(x) − branch(0)‖
```

- **分子**：扰动**另一侧**通道后，本分支输出的变化量（理想 = 0）；
- **分母**：本分支输出相对 0 的总变化量级 —— **数据/输出属性，不会退化为 0**，
  且能抓住「把通道彻底无视」的退化解（此时分母→0，反而不判合格）。

⭐ 关键认识：交叉扰动是在**批维**上打乱的（样本 i 拿到样本 `perm[i]` 的另一侧通道），
这**必然打散原有配对**。所以**不能**去比「扰动后的输出 vs 原配对的目标」——
那样连 oracle 都会被判必错（实测假误差 **0.97 / 0.73**）。
**问的必须是「不变性」，不是「预测精度」。**

## 3. 装置（`kp/latent/separation.py`）

| 件 | 作用 |
|---|---|
| `synthetic_batch(mix=...)` | 合成 40ch latent：语义块=结构（矩形+低秩场）、细节块=样式（高频噪声+色偏） |
| `structural_metric` | **边缘能量图**上的归一化 L1 —— 对应「空间结构」，不受色偏干扰 |
| `texture_metric` | 通道均值 + 空间标准差 —— 对应「样式」 |
| `SeparationModel` | 双分支 1×1 线性混合：**输入看全 40ch**（否则分离成循环论证），**输出各自只出自己那块** |
| `cross_perturb` | `shuffle_detail` / `shuffle_semantic` / `reverse`，**只动目标通道块** |
| `recon_loss` | **分块**重建损失 + 交叉扰动不变性正则（`w_inv`） |
| `_Oracle` / `_Leaky` | 尺子的**正例 / 反例**（必须在同一装置上分别 PASS / FAIL） |
| `evaluate` / `run_g2` | 出报告；`run_g2` **强制同时跑两个 mix 档** |

### 3.1 ⭐ `mix` 是本装置最关键的旋钮

| mix | 数据性质 | 用途 |
|---|---|---|
| **0.0** | 语义块**只**含结构、细节块**只**含样式 ⇒ **分离是白送的** | 证明装置**不误报**（负对照也该 PASS） |
| **0.6** | 细节块里**也掺入**结构 ⇒ 「顺手从细节块读结构」变成**捷径** | 证明**监督真的有用**（负对照走捷径 ⇒ FAIL） |

🔴 **只跑一个 mix 会得出错误结论**：本装置第一版只跑 `mix=0`，结果 `w_inv=0`（去掉监督）
**也 PASS** ⇒ 看起来「显式监督没用」。加入 `mix=0.6` 才有分辨力。

## 4. 实测结果（合成数据 · 纯 CPU · ~78s）

### 4.1 尺子双向校验（**先过这一关，后面数字才可信**）

| 被测对象 | 语义分支依赖 | 细节分支依赖 | 判定 |
|---|---|---|---|
| **oracle**（语义分支只吃语义块） | **0.0000** | **0.0000** | ✅ **PASS**（输出逐位不变） |
| **leaky**（语义分支实际读细节块） | **0.592** | 0.0000 | ❌ **FAIL** ✅正确 |

### 4.2 监督的净收益（`mix=0.6`，取最差的一侧）

| 配置 | 最差依赖度 | 判定 |
|---|---|---|
| 负对照（`w_inv=0`，无显式监督） | **0.5340** | ❌ FAIL（走捷径） |
| **有显式监督（`w_inv=1.0`）** | **0.0654** | ✅ PASS |
| **净收益** | —— | **8.17×**（自检里跑到 41.5×） |

门线 `max_dep = 0.20`。三种扰动（`shuffle_detail` / `shuffle_semantic` / `reverse`）结论一致。

### 4.3 `mix=0` 档（无假阴性证明）

有监督 0.0561 PASS ／ 负对照 0.0632 **也 PASS** —— 这正是「分离白送」的预期表现，
**不能**拿它当「监督有用」的证据。

## 5. 自检接入（`kp/selftest.py` 第 19 节，5 项）

1. **尺子双向校验**：oracle 必过 + leaky 必挂
2. **显式监督确有净收益**：`mix` 对照（非单点）
3. **退化输入报缺口**：`batch=1` 必须报错，不许静默返回「全过」的假报告
4. **MI 惩罚能分辨**独立/耦合（独立 0.00193 < 耦合 0.06503）
5. **扰动算子语义**：只动目标通道块

自检总数 **52 → 57**（原 52 项无回归）。

## 6. ⚠️ 局限（**必读，别把合成结论当终局**）

1. **这是合成数据**：它证明的是「**装置正确 + 监督有效**」，**不等于真图上也能分离**。
   真图版需要接**真实 VAE 编码器**（32× DC-AE 式）与真实图像数据。
2. **`mix` 是人为构造的串扰**：真实数据的串扰结构未知，`mix=0.6` 不代表任何真实比例。
3. **`SeparationModel` 是 1×1 线性混合的小模型（无卷积、无注意力）**：它验的是**判据与监督机制**，
   不是主干本身。主干上的同类监督需要在 P2 换主干后接入。
4. **指标是代理量**：边缘能量/统计量是「结构/样式」的低成本代理，
   真图评估应补人可读的结构指标（如真实 SSIM/LPIPS 分支）与分布级指标（见补充09 §9.2 的判据修订）。
