# KokonaPolaris（心夏北极星 / KP）项目长期记忆

> 只留「决策 + 硬约束 + 结论 + 协作约定」。**实测数字见 `MEMORY_archive.md`**；**本机操作细节见 `MEMORY_ops.md`**；逐日细节见 `2026-10-*.md`；正式结论见 `D:/model/design/`。

## 项目性质与定位
用户（自研向模型设计爱好者，愿担高风险）委托设计的**全新文生图架构**（非 SDXL/Flux 修补）。**主打二次元/日系，写实为主干内生 domain 旋钮**。当前：**设计收敛，G1 初步通过，骨架代码已落地**。
- **产品 = ① 文本塔（~220M LLM，自蒸馏）+ ② 自研 DiT 主干（0.6B/1.5B）+ ③ VAE + ④ 可选能力挂件**。是**文生图视觉生成模型**；我的角色是**造机器、不开机器**。
- ⚠️ **三个必须主动澄清的误解**：① 「教师」≠「底模」→ **KP 无底模，一个权重都不继承**；② 「我不生成图像内容」≠「项目不是视觉模型」；③ Sana/Z-Image 不是「接了两个生图模型」→ 只是工具（**试件 / 教师**）。

## 命名
正式名 **KokonaPolaris-S4**（中文 **心夏北极星**，缩写 **KP**）。`-S4` = Single-stream + native FP4。
Polaris 双关「北极星 + 极性/对偶」：语义·细节双通道 latent / 正·背对偶视图 / 擦除·恢复对偶算子。
尺寸档 **KP-S 0.6B（主力）/ KP-M 1.5B（质量）/ KP-L 3B（仅 teacher，不发布）**。旧代号 POCKET-DiT/囊萤 全废。

## 硬约束（不可动摇）
1. **NVFP4 原生**，兼容 Blackwell **SM120**（RTX 50 系，最低 8GB）。SM120 **无 tcgen05/TMEM**、共享内存 99KiB（SM100 为 228KiB）→ 不能直搬官方 kernel。
2. **低显存优先**：显存效率是第一设计变量（不是「为 8GB 定制」）。
3. **弃用 UNet**，主干走 DiT。
4. **LoRA 训练极简易**：角色正视图 + 背视图即可训好，**不与底模打架**；低数据训练必须可行。

## 架构核心
- **第一性原理：显存第一因是 token 数，不是参数量。** 优先级 `latent 压缩率 > 注意力复杂度 > 权重位宽 > 参数量`；NVFP4 是二级放大器。
- 主干：单流 DiT；混合注意力 **3:1（gated linear : Sigmoid/Softpick 非归一化）**；Rectified Flow + logit-normal + QK-Norm；浅层前 4–6 block 保留 double-stream。
- 混合 Latent：**32× 空间压缩**，语义 8ch（对齐 DINOv3）+ 细节 32ch（DC-AE 式）→ 1024² 仅 **1024 token**。
- CharaBridge：多视角身份 + 几何双分支，gated 注入，可关断（bit-exact）。
- 显存目标：推理 **~2.5GB @1024²**；LoRA 训练 **~4–5GB**。

## 关键设计决策（勿重复推翻）
- **不打架四机制**：通道分离 / 正交注入（门控初始 0）/ Latent 解耦 / 可关断 bit-exact。
- **能力总线**：冻结主干 + 可插拔包 `{ΔW, g, 元数据}`；全门控=0 时 bit-exact（靠**整条旁路短路**，不是乘 0）；**注入点必须绕过 NVFP4 量化器**。
- ⭐ **双向包体系**：**∥-Pack**（旁路，100M–1B，物理上不可能覆盖底模 → 跨域：写实/文字）/ **Δ-Pack**（权重扰动 27MB，必须锁 `W₀` 的 SVD 子空间 → 同域长尾：笔触/色调）/ **SVDPack**（`ΔW=Ũ·ΔΣ·Ṽᵀ`，可训参数仅 rank 个，基被存储 ⇒ **按构造无入侵维度 + 跨版本可迁移**）。**「ΔW 可入侵底模，旁路与条件不能」——能力越大越域外，越不能住 ΔW 里。**
- ⭐ **「打架」物理机理**：LoRA 产生**入侵维度**（正交于 `W₀` 奇异向量的全新高排名分量，arXiv 2410.21228），全量微调不产生 → **「禁止入侵维度」条款**：Δ-Pack 建在 `W₀` SVD 子空间；训练后**谱检查**，与 `W₀` 全奇异向量 cos<0.1 的高排名分量判不合格。
- **Δ-Pack 规格**：块对角分解（RaLoRA 式，有效秩 r→n_l×r）+ rsLoRA `α/√r` + 按 **GID** 分层 + **`W_o` 优先预算**。**LoRA 瓶颈不是「低秩」，是「低的有效秩」。** ⚠️ 块对角包做谱检查**必须逐对角块**（用全局子空间会误报）。
- ⭐ **身份载体是一等公民**：身份由数据对象 **「角色卡」**承担（**2.5D 分层 19 类语义层 + 遮挡补全 + 伪深度绘制序 + 身份 token**，1–5MB，**不依赖底模坐标系 → 跨版本通用**）。① 训 **Character Fitter** ② 换角色 = Fitter 前向一次（**秒级**，峰 ~1.2GB）③ 可选精修。**二次元的正确表征是 2.5D 分层不是 3D 网格**（See-through, SIGGRAPH 2026）。
- **身份 token 走 cross-attention，不拼主序列**：预算 **256 token**（全图仅 1024 图像 token，拼接会让注意力成本 ×4）；挂少数锚点层；与文本 token 隔离；g=0 时 bit-exact。
- ⚠️ **可关断 = 返回 `None`，不是零向量**（零向量进 cross-attention 仍算出非零，**「乘 0 再相加」≠「不计算」**）。另：**adaLN-Zero 让身份门控初始为 0** ⇒ 初始化时注入身份 token 也不改变输出，要观察联动须先显式开门。
- **主干双域预训练 + domain 条件向量**：默认 anime，可切 photo/semi-real → 写实是**内生旋钮**。**必须在预训练阶段决定**；退路：事后域包**必须 ∥-Pack**（体量大两个数量级，需重训）。
- **ComfyUI 不依赖**：真成本在架构特征不在节点（三硬骨头 = 40ch 混合 latent / 非 softmax 注意力 / 能力总线门控）。主交付 = **diffusers `ModelMixin` + 单文件 safetensors + 30 行推理脚本 + Gradio**；预留四接口（同构单文件权重 / latent 打包解包纯函数 / **attention 可替换** / 统一 `load_adapter()`）。⚠️ **NVFP4 单文件在 ComfyUI 可用性未验证 → 并入 P0。**
- **TypographyPack 与角色卡共用同一套分层表示**（19 类语义层 + 文本框层）。
- **可插拔判据（三问）**：**⓪ 这个轴存在吗、可靠吗？**（未过 G3.5 → 不信任 L1，落 L2/L3）→ ① 底模见过吗？（没见过 → ∥-Pack）→ 见过则 ② 被人为抑制过吗？（是 → **恢复型闭式 `E⁻¹`，秒级**；否 → 长尾型 Δ-Pack，小时级）。
- ⭐ **可逆擦除账本**：把合规抑制实现为**显式低秩算子** `E = Σαᵢuᵢvᵢᵀ` + 记录 {基/有效秩/作用层/强度/保留集边界} ⇒ **`Pack_recover ≡ E⁻¹`（加能力 = 减能力取反）**。依据：擦除多为引导式回避（2505.17013）；安全微调是近正交 ΔW + 零空间投影；安全子空间有效秩 k≈6（LoX）；闭式擦除 22s（CURE, 2025）。**因自己做数据过滤 → 我们知道擦了什么**。作用层选在语义已分化深度之后（~2/3）。门控默认 0 ⇒ 接口成本为零。
- **能力成本三档**：秒级·闭式（恢复被抑制能力）｜小时级（长尾，Δ-Pack）｜天级（跨域，∥-Pack）。**恢复型包允许轻量非线性** `σ(XD)U`（压缩损失常非低秩）。
- **部署三层责任**：模型层（干净底座+门控+账本）/ 包层（能力）/ 部署层（策略）。**不在权重里内建部署层策略**（训练期对齐工程上不可靠：无害数据微调 2 epoch 即可把拒绝率从 ~0% 打到 50%+）。
- **32× 压缩与文字互斥**：40px 汉字仅占 1.25 latent 格 → 编码阶段被丢弃。**主干不动，文字走独立低压缩 ROI 分支（TypographyPack, <0.6B）** + Layout Planner（100M–1B, 纯 JSON、确定性）。**已实证**：Sana 32× DC-AE 输出「心夏北极星」→ 乱码；我们自己的 T0 链路 5 字 1 glyph 全中。
- **必做：通道分离显式监督**（交叉扰动/反向扰动/通道互信息惩罚）。否则主干把两通道都塞满 → 画风解耦失效 → L1 全废。
- ⭐ **文本塔语言能力 = 设计变量**：SDXL 必须全英文（塔是 **CLIP**，中文 token 未训过 → 噪声）；**KP 天生支持中文**（塔 = ~220M **LLM**，自 **Qwen3-4B** 蒸馏）。⇒ **输入从「逗号标签串」变为「自然语言句子」；tag 退到「内部条件轴训练标签」。** ⚠️ **但中文能力不是白送的** —— 取决于训练数据中文 caption 占比 ⇒ **是个旋钮**（中文为主 + 10–20% 英文对齐；不许写标签串）。已落补充11 §4.8 / 路线 P1.8。
- **三层控制栈**：L1 主干内生条件轴（**调用量 ~90%**，零成本）+ L2 外置条件编码器（~9%，身份必须外置）+ L3 子空间约束 LoRA（~1%）。**让 LoRA 只做长尾。**
- ⭐⭐ **L1 基座依赖 = 全案第三个隐藏关键假设**：⚠️ 90/9/1 是**调用量分布不是能力分层** —— **「L1 覆盖 90% 调用量，L3 承担 100% 兜底责任」**。三风险：① 覆盖率假设（轴不够广则 L1 **不存在**）；② 不可验证不可修（L1 出错**只能重训主干** → 控制权无声转移给基座）；③ ⚠️ **低比特下轴被抹平**（FP4 激活仅 16 级 E2M1 → 旋钮行程变短）。另：条件轴互相耦合。**加固**：**Axis Probe + 门 G3.5**（单调/正交/可逆/**低比特行程**四测，未过默认归 L3）；**Style-Pack**（风格走载体）；设计律**「控制权原则」：能显式写入的，就不要隐式请求**。⭐ **免费正交监督**：shader 配对数据（同场景不同 shader）→ 条件向量差异只应落风格维 → 可把 L1 改造成**已标定控制面板**（16 维逐维命名）。
- **ControlNet/图生图**：ControlNet 等价物 = 「条件包」（能做但贵，独立分支+天级重训，**不进当前预算**）；参考图理解 = CharaBridge（内建，比 IP-Adapter 强，多解几何 normal/depth/ray-pose）。⚠️ **40ch 混合 latent 使下游 img2img/inpaint/放大全需重写**。用户「只为生成角色才需要它」的判断成立。
- **能力包默认 SVD 子空间约束**（LoRA-X 式）→ 零成本跨自家主干版本可迁移。**Matryoshka 分辨率**：早期 256 token → 后期 1024（PostDiff：FID 18.42→15.69，FLOPs −60%）；必须一开始留好位置编码与噪声调度。
- **数据多引擎（四旋钮）**：字形光栅化 + **视角/着色器/分层可见性/姿态**（正交 → 配对样本组合式扩增）。原则：**让渲染器生产数据而非爬图**；**用结构性先验换数据量**。
- **可行性更正**：别说「从零预训练要千万级算力」。Micro-Budget（2407.15811）1.16B + 3700 万图 = **$1,890**，COCO FID 12.7（256→512 渐进 + 75% patch masking）。
- **不做**：不量化 VAE；不缓存文本 embedding；不做 10B+；不做纯自回归/VAR；不做双流 MMDiT。**未检假设（先测不改）**：文本 token 是否从变长 200 压到固定 64 语义槽。

## G1 / 量化（完整见 archive + 补充09）
- **G1 靶子 = Sana 1.6B**（Apache 2.0，11GB）。选它因**与 KP 同构**：1024² → latent (1,32,32,32)、`patch_size=1` ⇒ **token 数 1024 ＝ KP 目标**；VAE = DC-AE 32×。⇒ G1 结论可外推不打折。
- ✅ **G1 快速判据**：`d_quant/d_ref` = **W4A8 0.535 / W4A16 0.527 / W4A4 0.889**（d_ref=14.576）→ 三臂全 <1 ⇒ **初步通过（设计档 W4A8）**。**唯一遗留 = 正式 FID（≥50 张/臂，需白天解锁）。**
- **E5（15 例）**：W4A4 29.72% / **W4A8 9.98%** / W4A16 7.74% —— **误差几乎全来自激活量化** ⇒ 支持「FP4 权重 + FP8 激活」；误差随 t 呈**倒 U**。
- **E5b 可训性**：ModelOpt fake-quant 无反向 ⇒ 崩；**真根因 = 插件把 SDPA 换成无 backward 的 `FP8SDPA`**（与量化器无关），patch 回原版即解。**全参 QAT 本机不可行**（AdamW ≈12.8GB）⇒ **必须 adapter 式 QAD**。
- 🔴 **永久规范**：① 逐像素 PSNR/SSIM 只用于同轨迹复现性，**不可判画质** → G1 主判据须分布级；② PTQ 是模拟量化，其峰值显存**不能论证 NVFP4 显存收益**。
