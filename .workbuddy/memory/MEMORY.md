## 关键决策（勿重复推翻）
- **VAE 用现成 DC-AE f32c32（32ch）**：40ch 混合 latent 的分离前提被自家实测推翻（训练后 R²=0.9997 vs DC-AE 随便切 0.4375），且与 G1 靶子 Sana 同 VAE ⇒ G1 结论可直迁。自训 HybridVAE 线归档（rFID 87.3 vs 门线 40）。
- **糊 = 训练量不足**（过拟合 100 张即出清晰二次元角色 ⇒ 链路正确）；第一张图后所有症状都指向训练量。
- **「模型不听提示」病根** = 条件对比损失缺失 + 无 CFG dropout。修法：`--cls-w` + `--p-drop 0.1`（默认）+ 分组学习率（新模块 lr ×5~10，+21%）。判据 `tools/ovf_probe.py` 信号/基线 ≥30%。
- 文本教师 = Qwen3.5-4B-Base（10-05 换版；vocab 实测 248077，禁照抄卡片）；「剥离视觉」= 不取视觉塔，无需写代码。
- KP-M = L28/dim1792 = 1.656B（+10.4% vs 标称；改结构/改标称仍待拍板）。
- 数据：Danbooru curated 338,011 张，`explicit_ok` 全量（项目决策）；rating 从 prompt 裸 token **整词匹配**；AVIF 35ms/张 ⇒ `shard_stream` 多进程（GPU 0%→80%）。
